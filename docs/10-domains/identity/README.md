# Identity Domain

Estado: Core Domain
Prioridad: P0

---

## Propósito

El dominio Identity representa quién es el usuario dentro de Forge.

No almacena únicamente información personal.

Almacena la evolución de la identidad deportiva.

---

## Responsabilidades

- Perfil.
- Objetivos.
- Nivel.
- XP.
- Títulos.
- Preferencias.
- Historial deportivo.
- Configuración.

---

## No es responsable de

- Entrenamientos.
- Progreso.
- IA.
- Comunidad.
- Rutinas.

---

## Filosofía

Las personas no vuelven porque tienen una cuenta.

Vuelven porque sienten que esa cuenta representa quiénes son.

Forge debe convertirse en el lugar donde el usuario construye su identidad como atleta.
