# Misión

Ayudar a las personas a construir disciplina utilizando evidencia objetiva de progreso.

No creemos que la motivación sea suficiente.

Creemos que las personas continúan cuando pueden ver claramente que están mejorando.

Forge convierte el entrenamiento en una historia.

Cada entrenamiento añade una página.

Cada récord añade un capítulo.
Cada año añade un legado.
